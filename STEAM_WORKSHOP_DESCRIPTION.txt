[h1]PWS MCP Server[/h1]

[b]Connect Codex, Claude Desktop, Claude Code, and other local MCP clients to Pro Wrestling Sim.[/b]

Ask an AI assistant to search your loaded save, analyze your company, recommend workers, review contracts, plan storylines, and draft or apply complete show cards.

The server uses PWS's official plugin APIs. Database exploration is read-only. Save-changing actions are validated by PWS and require confirmation.

[h2]Features[/h2]

[list]
[*]Search workers, companies, shows, titles, stories, teams, stables, venues, and news.
[*]Analyze finances, payroll, roster balance, availability, titles, and storylines.
[*]Find realistic hiring targets and review expiring contracts.
[*]Inspect detailed worker profiles, relationships, chemistry, and history.
[*]Plan and validate complete show cards before applying them.
[*]Book matches and angles, manage storylines, sign or release workers, and manage titles.
[*]Inspect the database schema and run limited, read-only queries.
[/list]

[h2]Requirements[/h2]

[list]
[*]Windows and Pro Wrestling Sim
[*][url=https://nodejs.org/en/download]Node.js 18 or newer[/url] - choose the LTS download
[*]At least one local AI client: Codex, Claude Desktop, Claude Code, or another stdio MCP client
[/list]

No npm package installation is needed.

[h1]Quick Installation[/h1]

[h2]1. Install the PWS plugin[/h2]

1. Click [b]Subscribe[/b] on this page and wait for Steam.
2. Restart PWS.
3. Enable [b]PWS MCP Server[/b] in the plugin list on the splash screen.
4. Load a save.

The plugin works in the background, so it does not add an in-game page.

[h2]2. Check Node.js[/h2]

Open PowerShell and run:

[code]node --version[/code]

The first number must be 18 or higher.

[h2]3. Check the server path[/h2]

The normal Workshop path is:

[code]C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\3780507815\plugins\pws-mcp-server\mcp-server.js[/code]

Check it in PowerShell:

[code]Test-Path 'C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\3780507815\plugins\pws-mcp-server\mcp-server.js'[/code]

The answer should be [code]True[/code]. If Steam is installed in another library, use that library's path instead.

[h2]4. Connect one or more AI clients[/h2]

You may configure every client below and switch when one reaches its usage limit. They all use the same plugin and server path. To avoid conflicting actions, use only one client at a time when changing your save.

[h3]Codex app or IDE extension[/h3]

1. Open [b]Settings > MCP servers > Add server[/b].
2. Name: [code]pro-wrestling-sim[/code]
3. Type: [code]STDIO[/code]
4. Command: [code]C:\Program Files\nodejs\node.exe[/code]
5. Argument: the full [code]mcp-server.js[/code] path above.
6. Save and restart Codex.

Codex CLI alternative:

[code]$server = 'C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\3780507815\plugins\pws-mcp-server\mcp-server.js'
codex mcp add pro-wrestling-sim -- "C:\Program Files\nodejs\node.exe" $server[/code]

[h3]Claude Desktop[/h3]

1. Open [b]Settings > Developer > Edit Config[/b].
2. Put this in [code]claude_desktop_config.json[/code]:

[code]{
  "mcpServers": {
    "pro-wrestling-sim": {
      "command": "C:\\Program Files\\nodejs\\node.exe",
      "args": [
        "C:\\Program Files (x86)\\Steam\\steamapps\\workshop\\content\\1157700\\3780507815\\plugins\\pws-mcp-server\\mcp-server.js"
      ]
    }
  }
}[/code]

3. Save, fully quit Claude Desktop, and reopen it.

[h3]Claude Code[/h3]

Run in PowerShell:

[code]$server = 'C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\3780507815\plugins\pws-mcp-server\mcp-server.js'
claude mcp add --scope user pro-wrestling-sim -- "C:\Program Files\nodejs\node.exe" $server[/code]

Check it with [code]claude mcp list[/code] or [code]/mcp[/code].

[h2]5. Test it[/h2]

Keep PWS open with a save loaded, then ask your AI:

[quote]Connect to Pro Wrestling Sim and tell me the loaded save, current date, player promotion, company size, and cash balance.[/quote]

If it answers with information from your save, setup is complete.

[h2]Safety and Limitations[/h2]

[list]
[*]The bridge is local-only and protected by a random token.
[*]Raw database queries are read-only and limited in size.
[*]Save-changing actions require confirmation and are audited by PWS.
[*]Automatic show cards are drafts; review them before applying.
[*]Contract renewals are advisory until PWS provides a validated renewal action.
[/list]

[b]Back up important saves before using any plugin that can perform game actions. Never share [code]%APPDATA%\ProWrestlingSimulator\mcp\pws-mcp-runtime.json[/code].[/b]

[h2]Quick Troubleshooting[/h2]

[list]
[*][b]Bridge offline:[/b] Start PWS, enable the plugin, and load a save.
[*][b]Server file missing:[/b] Check whether Steam uses another library or drive.
[*][b]Node not recognized:[/b] Install Node.js LTS and restart Windows.
[*][b]Tools missing:[/b] Restart PWS, then restart the AI client.
[*][b]No show available:[/b] Schedule an unfinished event in PWS first.
[/list]
