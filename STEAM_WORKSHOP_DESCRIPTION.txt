[h1]PWS MCP Server[/h1]

[b]Turn Claude Desktop, Claude Code, or Codex into a hands-on booking and company-management assistant for Pro Wrestling Sim.[/b]

PWS MCP Server gives compatible AI clients a structured, local connection to your loaded save. Ask questions in plain language, inspect what is actually in the game, build cards, manage your promotion, and preview supported changes before anything is applied.

[quote][b]Now available: 0.5.0 — the Company Management Update[/b]

This is the largest PWS MCP Server update so far. Version 0.5.0 fixes incomplete scheduled-show results and adds major base-game management tools for tag teams, brands, championships, contracts, storylines, events, commentary teams, networks, and advanced show booking.
[/quote]

[h2]What you can do[/h2]

[list]
[*][b]See your real schedule:[/b] find unfinished shows reliably across both native PWS event-instance paths
[*][b]Audit a show in one request:[/b] catch empty cards, invalid winners, title risks, repeated workers, and runtime problems
[*][b]Book deeper matches:[/b] create and edit matches and angles, including ordered entrances and eliminations for rumbles and other multi-person matches
[*][b]Manage tag teams:[/b] discover established teams whose members you employ, register them under their existing name, create new teams, edit members and experience, or dissolve them
[*][b]Run brands and commentary teams:[/b] create and edit brands, assign workers, and set default announcers for brands or recurring events
[*][b]Manage championships:[/b] create, edit, retire, reinstate, vacate, or award singles, tag, and trios titles
[*][b]Handle contracts and hiring:[/b] inspect cash-aware hiring guidance, modify supported contract terms, sign workers immediately, or release talent
[*][b]Build stories and events:[/b] create and edit storylines, manage their members, create event series, update recurring-event settings, schedule shows, and reschedule unfinished shows
[*][b]Understand your roster:[/b] include Occasional Wrestlers correctly and review appearances, matches, angles, last-booked dates, and rotation warnings
[*][b]Inspect television deals:[/b] browse networks, availability, and current deals, with verified cancellation support
[/list]

[h2]More base-game features[/h2]

[list]
[*]Browse companies, workers, contracts, titles, tag teams, stables, storylines, venues, events, shows, gimmicks, personas, and promises
[*]Build complete show plans with championships, ringside workers, referees, agents, announcers, and structured angle groups
[*]Use native wrestler personas or a contract-specific ring name without renaming the underlying worker globally
[*]Manage stables, gimmicks, promises, venues, event series, and scheduled shows
[*]Check future availability against injuries, rehab, suspensions, and time off on the actual show date
[*]Diagnose connection state, active transport, loaded-save state, and client/plugin version mismatches
[/list]

[h2]Designed for safe collaboration[/h2]

[list]
[*]Save-changing tools show a preview first
[*]A preview is not permission to apply a change
[*]The assistant applies a supported change only after you approve that exact preview
[*]The live target is checked again before applying the change
[*]The persisted result is verified before success is reported
[/list]

Back up important saves before using any tool that changes game data.

[h2]Install the PWS plugin[/h2]

[olist]
[*]Subscribe to this Workshop item.
[*]Let Steam finish downloading it, then restart Pro Wrestling Sim.
[*]Enable [b]PWS MCP Server[/b] in the plugin manager.
[*]Load your save.
[/olist]

[h2]Connect your AI client[/h2]

[b]Claude Desktop[/b]

Download and install [code]pws-mcp-server-v0.5.0.mcpb[/code] from the [url=https://github.com/Distortik/pws-mcp-server/releases/latest]matching GitHub release[/url]. Fully restart Claude Desktop, begin a new Home conversation, and enable Pro Wrestling Sim.

[quote][b]Important:[/b] Steam updates only the in-game plugin. It cannot update Claude Desktop's separately installed [code].mcpb[/code]. Update both halves whenever a new version is released.[/quote]

[b]Claude Code or Codex[/b]

Install Node.js 18 or newer, then ask the client to configure the Workshop server for you:

[quote]Locate the installed PWS MCP Server [code]mcp-server.js[/code] from my Steam Workshop installation. Configure my user-level MCP server named [code]pro-wrestling-sim[/code] to run it with Node, verify the saved entry, and tell me the exact path you selected. Do not guess my Steam library or edit unrelated MCP entries.[/quote]

Restart the client after configuration or after a Workshop update so it reloads the current tool catalogue.

[h2]Test the connection[/h2]

[quote]Use the PWS MCP server to show my current game state and connection information.[/quote]

With PWS running and a save loaded, the assistant should return the current date, player company, and matching 0.5.0 connection details.

[h2]Troubleshooting and documentation[/h2]

[list]
[*]Restart PWS after installing or updating the Workshop item
[*]Restart the AI client after installing the MCPB or changing a direct-path configuration
[*]If old tools appear, verify which [code]mcp-server.js[/code] path the client is loading
[*]If the bridge is offline, confirm the plugin is enabled and a save is loaded
[/list]

Read the [url=https://github.com/Distortik/pws-mcp-server#readme]complete setup and troubleshooting guide[/url], the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3780507815]Workshop release notes[/url], and the roadmap discussion for what comes next.
