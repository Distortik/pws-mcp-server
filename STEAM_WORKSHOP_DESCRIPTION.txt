[h1]PWS MCP Server[/h1]

[b]Connect Codex, Claude, Claude Code, and other MCP-compatible AI clients to Pro Wrestling Sim.[/b]

PWS MCP Server gives your AI assistant live, structured access to the save currently loaded in Pro Wrestling Sim. Use natural-language requests to search the game world, analyze your company, find hiring targets, review contracts, plan storylines, and draft or apply complete show cards.

The server uses PWS's official plugin APIs. Database exploration is read-only, while save changes go through validated PWS actions and require confirmation.

[h2]Main Features[/h2]

[list]
[*][b]Universal search[/b] — Find workers, promotions, shows, titles, storylines, tag teams, stables, venues, and news.
[*][b]Company analysis[/b] — Review company size, cash, finance history, payroll, roster balance, availability, titles, storylines, and management alerts.
[*][b]Hiring recommendations[/b] — Rank realistic targets using company size, cash pressure, payroll, home market, roster gaps, requested needs, skills, popularity, availability, risk, and estimated wage fit.
[*][b]Contract advice[/b] — Identify priority renewals, retention candidates, renegotiation targets, and possible releases using expiry, pay, usage, performance, momentum, morale, and finances.
[*][b]Detailed worker profiles[/b] — Inspect attributes, contracts, relationships, chemistry, storylines, and history.
[*][b]Booking assistant[/b] — Read the existing card, eligible roster, championships, active stories, recent matches, brand restrictions, and remaining show time.
[*][b]Auto-booking[/b] — Generate a complete dry-run card, validate it against the live save, review it, and apply it only after confirmation.
[*][b]Creative and management actions[/b] — Book matches and angles, manage storylines, sign or release workers, award or vacate titles, and create news or email items through PWS's validated action API.
[*][b]Advanced database access[/b] — Inspect the PWS schema and run parameterized read-only SQL for questions not covered by a dedicated tool.
[/list]

[h1]Installation Tutorial[/h1]

[h2]Step 1: Subscribe and enable the plugin[/h2]

1. Subscribe to this Workshop item.
2. Start or restart Pro Wrestling Sim so it can install and load the item.
3. Find [b]PWS MCP Server[/b] in the plugin list on the PWS splash screen.
4. Make sure the plugin is enabled.
5. Load a save.

The plugin runs in the background; it does not currently add an in-game page.

Steam installs this Workshop item under its numeric item ID. The MCP server path will be:

[code]C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\<WORKSHOP_ITEM_ID>\plugins\pws-mcp-server\mcp-server.js[/code]

Replace [code]<WORKSHOP_ITEM_ID>[/code] with this item's numeric Steam Workshop ID. It is the number in the Workshop page URL and the folder name directly below [code]1157700[/code]. If Steam is installed in another library, use that library's [code]steamapps\workshop\content\1157700[/code] folder instead.

[b]GitHub/manual installs only:[/b] The equivalent server path is [code]%APPDATA%\ProWrestlingSimulator\plugins\pws-mcp-server\mcp-server.js[/code]. The [code]%APPDATA%[/code] path is not the Workshop installation path.

[h2]Step 2: Check Node.js[/h2]

Open PowerShell and run:

[code]node --version[/code]

The version must be 18 or newer. If Windows cannot find [code]node[/code], install Node.js and then open a new terminal.

[h2]Step 3: Connect Codex[/h2]

In the Codex app or IDE extension:

1. Open [b]Settings > MCP servers > Add server[/b].
2. Choose [b]STDIO[/b].
3. Use the name [code]pro-wrestling-sim[/code].
4. Use [code]C:\Program Files\nodejs\node.exe[/code] as the command.
5. Add this argument, replacing the Workshop item ID:

[code]C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\<WORKSHOP_ITEM_ID>\plugins\pws-mcp-server\mcp-server.js[/code]

6. Save the server and restart Codex.

Alternatively, add this directly to [code]%USERPROFILE%\.codex\config.toml[/code], replace [code]<WORKSHOP_ITEM_ID>[/code], and restart Codex:

[code][mcp_servers.pro-wrestling-sim]
command = "C:\\Program Files\\nodejs\\node.exe"
args = ["C:\\Program Files (x86)\\Steam\\steamapps\\workshop\\content\\1157700\\<WORKSHOP_ITEM_ID>\\plugins\\pws-mcp-server\\mcp-server.js"]
enabled = true[/code]

If the Codex CLI is installed, the PowerShell alternative is:

[code]$server = 'C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\<WORKSHOP_ITEM_ID>\plugins\pws-mcp-server\mcp-server.js'
codex mcp add pro-wrestling-sim -- node $server[/code]

[h2]Step 4: Connect Claude Desktop[/h2]

Add this entry to [code]claude_desktop_config.json[/code], then restart Claude Desktop:

[code]{
  "mcpServers": {
    "pro-wrestling-sim": {
      "command": "powershell.exe",
      "args": [
        "-NoProfile",
        "-Command",
        "& (Get-Command node).Source 'C:\\Program Files (x86)\\Steam\\steamapps\\workshop\\content\\1157700\\<WORKSHOP_ITEM_ID>\\plugins\\pws-mcp-server\\mcp-server.js'"
      ]
    }
  }
}[/code]

[h2]Step 5: Connect Claude Code[/h2]

Run in PowerShell:

[code]$server = 'C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\<WORKSHOP_ITEM_ID>\plugins\pws-mcp-server\mcp-server.js'
claude mcp add pro-wrestling-sim -- node $server[/code]

[h2]Step 6: Test the connection[/h2]

Restart the AI client. Keep Pro Wrestling Sim running with the plugin enabled and a save loaded, then ask:

[quote]Connect to Pro Wrestling Sim and tell me the loaded save, current date, player promotion, company size, and cash balance.[/quote]

If those details are returned correctly, the connection is ready.

[h2]Safety[/h2]

[list]
[*]The bridge listens only on [code]127.0.0.1[/code] and requires a randomly generated local token.
[*]Raw SQL access is read-only, rejects stacked statements, and limits result size.
[*]Save-changing actions use PWS validation and its plugin audit log.
[*]Generic write actions require an explicit confirmation flag.
[*]Show booking is separated into planning, validation, and confirmed application.
[*]If part of a multi-segment booking fails, the plugin attempts to remove segments created earlier in that operation.
[/list]

[h2]Troubleshooting[/h2]

[list]
[*][b]Bridge offline:[/b] Start PWS, enable the plugin, and load a save.
[*][b]Player promotion missing:[/b] Reload the plugin and restart the MCP client. Version 0.2 and newer include a save-database fallback for promotion detection.
[*][b]New tools missing:[/b] Restart PWS and then restart the AI client.
[*][b]No show can be planned:[/b] Schedule an unfinished event in PWS first.
[*][b]Node is not recognized:[/b] Install Node.js 18 or newer and reopen the client.
[*][b]Codex command is not recognized:[/b] Configure the Codex app directly; the Codex CLI is optional.
[*][b]Server file not found:[/b] Replace [code]<WORKSHOP_ITEM_ID>[/code] with this item's number and check whether your Steam library is installed on another drive.
[*][b]Action rejected:[/b] PWS validates action inputs. Ask the assistant to inspect the returned error and the MCP action audit log.
[/list]

[h2]Current Limitations[/h2]

[list]
[*]Local clients only; no remote HTTP transport yet.
[*]PWS exposes signing and releasing actions but no dedicated validated contract-renewal action, so renewal terms are advisory.
[*]Automatic cards are drafts. Always review winners, finishes, title stakes, and storyline continuity before applying them.
[/list]

[b]Important:[/b] Back up important saves before using any plugin that can perform game actions. Never share the generated [code]%APPDATA%\ProWrestlingSimulator\mcp\pws-mcp-runtime.json[/code] file.
