[h1]PWS MCP Server[/h1]

[b]Connect Pro Wrestling Sim to Claude Desktop, Claude Code, or Codex.[/b]

Ask your AI assistant to inspect your save, plan shows, check workers and storylines, validate bookings, and perform supported changes through preview-first tools.

[quote][b]Known Claude Desktop issue[/b]

The 0.4.0-beta.4 MCPB currently installs and launches on Claude Desktop for Windows, but regular Home chats cancel its connection after a 60-second initialization timeout. Claude Code, Claude Desktop's Code tab, and Codex direct-path connections remain usable. A focused 0.4.0-beta.5 compatibility fix is planned before the final 0.4.0 release.
[/quote]

[h2]Highlights[/h2]

[list]
[*]Browse companies, workers, contracts, titles, teams, stables, storylines, venues, events, and shows
[*]Build and validate complete show plans, including matches, angles, titles, ringside workers, referees, agents, and announcers
[*]Manage storylines, contracts, gimmicks, stables, venues, event series, and scheduled shows
[*]Preview supported save changes before applying them, then verify the result
[*]Diagnose booking availability and storyline attribution problems
[/list]

[h2]Install the PWS plugin[/h2]

1. Subscribe to this Workshop item.
2. Restart Pro Wrestling Sim.
3. Enable [b]PWS MCP Server[/b] in the plugin manager.
4. Load your save.

[h2]Connect your AI client[/h2]

[b]Claude Desktop[/b]

Download and install the matching [code].mcpb[/code] file from the [url=https://github.com/Distortik/pws-mcp-server/releases]GitHub release[/url], then restart Claude Desktop. Regular Home-chat use is currently affected by the beta issue above; use Code or Codex temporarily.

[b]Important:[/b] Steam updates only the in-game plugin. It does not update Claude Desktop's [code].mcpb[/code] file.

[b]Claude Code[/b]

Claude Code ignores [code].mcpb[/code] files. It must point directly at the server file you want to test. With Node.js 18 or newer installed, run:

You do not have to find or edit the path manually. Paste this request into Claude Code and let it configure and verify the entry for you:

[quote]Locate the installed PWS MCP Server [code]mcp-server.js[/code] for the build I am actually using (Workshop, manual, or TEST). Configure the user-level Claude Code MCP server named [code]pro-wrestling-sim[/code] to run it with Node, verify it with [code]claude mcp get pro-wrestling-sim[/code], and tell me the exact path you selected. Do not guess the Steam library or edit unrelated MCP entries.[/quote]

[code]
$server = "C:\Program Files (x86)\Steam\steamapps\workshop\content\1157700\3780507815\plugins\pws-mcp-server\mcp-server.js"
claude mcp add --scope user pro-wrestling-sim -- node $server
claude mcp get pro-wrestling-sim
[/code]

You can paste that block into Claude Code and ask it to run the commands for you. Restart Claude Code afterward. If Steam is on another drive, ask Claude Code to locate the path instead of guessing it. For beta testing, use the separately installed TEST plugin path.

[b]Codex[/b]

You can also paste this request into Codex instead of editing its settings manually:

[quote]Locate the installed PWS MCP Server [code]mcp-server.js[/code] for the build I am actually using (Workshop, manual, or TEST). Configure the user-level Codex MCP server named [code]pro-wrestling-sim[/code] to run it with Node, verify the saved MCP entry, and tell me the exact path you selected. Do not guess the Steam library or edit unrelated MCP entries.[/quote]

Codex can inspect the installed paths and run its MCP configuration command; approve the configuration change when prompted, then restart the MCP server/client.

[h2]Test the connection[/h2]

[quote]Use the PWS MCP server to show my current game state.[/quote]

If the game is running with a save loaded, the assistant should return the current date and company information.

[h2]Safety[/h2]

[list]
[*]A preview is [b]not[/b] permission to apply a change.
[*]The assistant should use [code]confirmed: true[/code] only after you approve that exact preview.
[*]Requests to inspect, check, test, or verify do not authorize persistent save changes or creative booking decisions.
[*]Back up important saves before testing beta features.
[/list]

[h2]Optional mod integrations[/h2]

Other mods are never required. PWS MCP can add optional compatibility when a mod exposes a stable, documented API. Mod authors can find the requested integration contract in the Workshop discussion: [b]For Mod Authors: Optional PWS MCP Integration Support[/b].

[h2]Troubleshooting and full guide[/h2]

[list]
[*]Restart the game after installing or updating the Workshop plugin.
[*]Restart the AI client after changing its MCP configuration.
[*]If Claude Code shows old tools, run [code]claude mcp get pro-wrestling-sim[/code] and verify the exact path it is loading.
[*]If connection fails, confirm the game is open, the plugin is enabled, and a save is loaded.
[/list]

For detailed setup, updating, beta testing, permissions, and troubleshooting, read the [url=https://github.com/Distortik/pws-mcp-server#readme]complete GitHub guide[/url].
