[h2]Updating[/h2]

[olist]
[*]Let Steam update the Workshop plugin and restart PWS.
[*]Confirm [b]PWS MCP Server 0.3.0[/b] is enabled in the PWS plugin list.
[*]If you use Claude Desktop, install the new [code].mcpb[/code] from GitHub Releases.
[*]Restart Claude Desktop and confirm [b]Pro Wrestling Sim[/b] is enabled in the Code conversation.
[/olist]
