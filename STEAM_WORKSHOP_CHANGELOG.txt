[h2]Wrestler personas and contract identities[/h2]

[list]
[*]Browse native PWS alter egos with their preferred gimmick, picture, mask, promotion restriction, and valid dates.
[*]Switch one promotion contract to a native persona or custom ring name without renaming the underlying worker globally.
[*]Change persona availability between promotion-specific and free use, with exact restoration support.
[*]Require an explicit creative-sandbox override before selecting a persona outside its native date range.
[/list]

This supports presentations such as The Undertaker, biker Undertaker, Mankind, or Dude Love when those alter egos exist in the loaded database. PWS stores one active presentation per contract rather than a separate persona for every match.

[h2]Updating[/h2]

[olist]
[*]Let Steam update the Workshop plugin, then restart PWS.
[*]Confirm [b]PWS MCP Server 0.4.0[/b] is enabled and load your save.
[*]If you use Claude Desktop Home, install [code]pws-mcp-server-v0.4.0.mcpb[/code] from GitHub Releases and fully restart Claude Desktop. Installing the same extension identity normally upgrades the existing version; uninstall first only if the new version does not appear.
[*]Start a new Home conversation and ask: [i]Use the PWS MCP server to show my current game state.[/i]
[*]If you use Claude Code or Codex, keep the existing stable Workshop path and restart the client so it reloads the 0.4.0 server and tool catalogue.
[/olist]

[b]Steam cannot update Claude Desktop's MCPB. Codex, Claude Code, and other clients that run the Workshop copy of [code]mcp-server.js[/code] directly do not install the MCPB.[/b]
